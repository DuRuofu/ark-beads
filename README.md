# ark-beads

一个用于 **《明日方舟》拼豆小游戏** 的自动化工具。

> 导入拼豆模板 JSON，自动识别游戏界面并完成拼豆操作。

---

## 项目目标

实现一个完全离线的桌面软件，支持：

- Windows
- macOS

用户只需要：

1. 打开游戏拼豆界面
2. 导入模板 JSON
3. 点击开始

程序自动完成整个拼豆过程。

---

## MVP 功能

### JSON 导入

支持导入拼豆模板（24×24）。

例如：

```json
{
    "width": 24,
    "height": 24,
    "pixels": [
        ...
    ]
}
```

---

### 自动识别游戏界面

自动定位：

- 拼豆画布（24×24）
- 调色板
- 游戏窗口

无需固定分辨率。

---

### 自动拼豆

根据模板：

- 自动切换颜色
- 自动点击对应格子
- 按颜色分组绘制，减少颜色切换次数

---

## 后续规划

### 图像转换

支持：

```
图片
    ↓
缩放 24×24
    ↓
官方 40 色量化
    ↓
生成模板
```

不再依赖第三方网站。

---

### 模板编辑器

支持：

- 像素编辑
- 实时预览
- 导入/导出 JSON

---

### 更多自动化

- 自动检测窗口
- 自动校准
- 多分辨率支持
- Retina / HiDPI 支持

---

## 技术方案

```
JSON
    │
    ▼
解析模板
    │
    ▼
识别游戏界面（OpenCV）
    │
    ▼
计算画布坐标
    │
    ▼
鼠标自动点击
```
