# ark-beads

一个用于 **《明日方舟》拼豆小游戏** 的自动化工具。

> 导入拼豆模板 JSON，自动识别游戏界面并完成拼豆操作。

---

## 项目目标

实现一个完全离线的桌面软件，支持：

- Windows
- macOS

用户只需要：

1. 打开游戏拼豆界面
2. 导入模板 JSON
3. 点击开始

程序自动完成整个拼豆过程。

---

## MVP 功能

### JSON 导入

支持导入拼豆模板（24×24）。

例如：

```json
{
    "size": 24,
    "cells": [
        {
            "x": 0,
            "y": 0,
            "seq": 1,
            "region": 1,
            "hex": "#FFFFFF",
            "palPos": "第1行第4列"
        }
    ]
}
```

当前兼容 [PRTS 像素画取色工具](https://prts.chongxi.us/) 导出的 JSON。透明格不进入模板覆盖任务；正式绘制前会先将整张画布统一刷成白色。

---

### 校准游戏界面

当前版本通过画布对角格中心的两点采集定位：

- 拼豆画布（24×24）
- 调色板
- 游戏窗口

程序根据官方客户端固定布局自动推算调色板。校准结果只保存在本机，游戏窗口位置不变时可重复使用；后续版本再加入自动识别。

---

### 自动拼豆

根据模板：

- 自动切换颜色
- 开始时用 24 条横向笔画铺设白色底层
- 自动点击对应格子
- 按颜色分组绘制，减少颜色切换次数
- 同色连续格按住拖过，减少操作次数
- 支持暂停、停止与屏幕左上角紧急停止

## 使用说明（当前版本）

1. 导入网站导出的 24×24 JSON。
2. 在“校准界面”中采集画布左上格与右下格的中心。
3. 首次使用时，允许 Ark Beads 使用 macOS“辅助功能”控制鼠标。
4. 先执行单格试点，确认画布和色板坐标正确，并在游戏中撤销试点格。
5. 从全新白色画布开始自动绘制。启动后有 4 秒时间切换回游戏。

绘制过程中不要移动游戏窗口。需要紧急停止时，将鼠标移至屏幕左上角；程序不会自动点击游戏内的保存或发布按钮。

采集坐标、单格试点和正式绘制期间，Ark Beads 会自动隐藏以露出单屏上的游戏窗口，并在操作结束后自动恢复到前台。

## 本地开发

需要安装 Node.js、Rust 和 macOS Command Line Tools。

```bash
pnpm install
pnpm tauri dev
```

运行检查：

```bash
pnpm check
pnpm build
cd src-tauri && cargo test
```

生成本机测试用的 macOS 应用：

```bash
pnpm build:mac
```

该命令会为应用附加固定的本地签名要求，避免每次重新构建后 macOS 将其识别成不同的“辅助功能”权限对象。正式分发版本仍应使用 Apple Developer ID 签名并公证。
